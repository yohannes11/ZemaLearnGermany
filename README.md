# ZemaLearnGermany

A German A1.1 course for beginners: Units 1–7 with vocabulary and grammar, natural-voice audio,
speaking practice with an animated coach, flashcards, matching quizzes, learner accounts and an admin report.

## Run it locally

```bash
python3 server.py
```

Then open http://localhost:8000/german-a1-course.html. No packages are needed; the server uses only
Python's standard library (Python 3.10 or newer).

The first visit to http://localhost:8000/admin.html, made from the same computer, creates the admin account.
On a server behind nginx, create it from the command line instead:

```bash
python3 server.py create-admin you@example.com "Your Name"
```

## Files

| Path | What it is |
|---|---|
| `german-a1-course.html` | The course (one page) |
| `course-data.js` | All vocabulary and grammar lessons, generated by `tools/course_content.py` |
| `audio/` | Recorded audio for every word and example, indexed by `audio/manifest.json` |
| `server.py` | Web server: accounts, progress sync, usage statistics, admin API |
| `admin.html` | Admin area: usage report and user management |
| `ads-config.js`, `ads.txt` | Google AdSense settings (placeholders until filled in) |
| `tools/` | Content source and audio generator (`pip install -r requirements.txt` for the audio tool) |
| `learning/` | Earlier Django version of the app (not used by the live site) |

Accounts and statistics are stored in `usage.db`, which is never committed.
